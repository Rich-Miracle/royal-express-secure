FIX - api.php dual purpose
==========================

Replaces server/api.php only. Extract over the previous file.

WHAT WAS WRONG
--------------
server/api.php is used in two different ways in this application:

  1. As the API endpoint, requested directly by the front-end JavaScript with
     a function_code in the query string.

  2. As a library. pages/head.php and Admin/pages/head.php include it on every
     single page render so the database functions are available to the page.

My authorisation gate treated both cases as requests, so every page load hit
the "Missing function_code" check and stopped there.

THE FIX
-------
The file now compares itself against the script the web server was actually
asked to run. A direct request is authorised as before. An include skips the
gate, loads the functions, and routes nothing.
