WHY HEADERS ARE IN .htaccess AND NOT PHP
----------------------------------------
index.php emits <!DOCTYPE html> before any PHP include runs, so output has
already started by the time PHP could call header(). Apache applies these
before PHP is involved, and it covers static files too.
